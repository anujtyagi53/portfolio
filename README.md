# Anuj Tyagi — Portfolio

Personal portfolio site, built with plain HTML/CSS/JS and deployed via GitHub Pages.

Live at: https://anujtyagi53.github.io/portfolio/

## Structure

- `index.html` — page content
- `css/style.css` — styling (light/dark mode via `prefers-color-scheme`)
- `js/script.js` — nav toggle + footer year
- `assets/resume/AnujCV_Updated.pdf` — downloadable résumé

## Local preview

Open `index.html` directly in a browser, or serve it:

```bash
python3 -m http.server 8000
```
